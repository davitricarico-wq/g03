HTTP Status Codes

Status Descrição
200 OK — Requisição bem-sucedida; recurso obtido ou atualizado
201 Created — Recurso criado com sucesso
400 Bad Request — Formato inválido ou parâmetros incorretos
403 Forbidden — Usuário sem permissão para acessar
404 Not Found — Recurso não encontrado
409 Conflict — Violação de regra de negócio (RF/RN)
422 Unprocessable Entity — Dados sintaticamente válidos, mas conteúdo inválido
500 Internal Server Error — Erro no servidor
GET /api/moradias
RF/RN RF006RN02
Atores A02A03
Descrição Lista com filtros avançados

Query Parameters

status string — Ativa, Demolida, Evacuada, Desapropriada
grupo_prioritario string — Idoso, Criança, Gestante, PCD, Acamado
desatualizado boolean — Cadastros sem atualização há 365+ dias
condicao_ocupacao string — Própria, Alugada, Cedida

Request

GET /api/moradias?status=Ativa&grupo_prioritario=Acamado

Response 200

[ { "id_moradia": 1, "bairro": "Centro", "status": "Ativa", "desatualizado": true, "risco_critico": true } ]

Status Possíveis

200 Lista retornada (pode estar vazia)
400 Filtro inválido
403 Sem permissão
